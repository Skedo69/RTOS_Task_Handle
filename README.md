# RTOS_Task_Handle
it handles external interrupt (calcswitch) 
two main tasks (inc,dec var)
uart task that sends data every 5 ticks 
*note tick is defined by 1ms and buadrate is 115200
*please check the com number of usb to ttl carefully before putting it in serial console to ensure that the data show correctly
